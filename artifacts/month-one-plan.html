Review these outcomes together

We should have

  • One aligned requirements baseline and a short first-release scope.
  • A current-code gap list and a consistent Vim-style keyboard map.
  • A documented CLI/TUI/filesystem interface map.
  • A small working read-only agent demonstration using real ruki system data.
  • A reproducible walkthrough and a prioritized next milestone.

We should not spend month one on

  • A custom ISO or installer.
  • Many new system-management modules at once.
  • Unrestricted AI shell execution or autonomous destructive actions.
  • GUI control panels or mouse-dependent workflows.
  • Multi-distro support, a plugin platform, or broad rollback promises.
